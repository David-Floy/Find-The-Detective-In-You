# Find The Detective In You

**Version 1.0**  
**Teamprojekt für die Modulabschlussprüfung AM 1: Medieninformatik**

---

## Beschreibung

"Find The Detective In You" ist ein interaktives Spiel, das im Rahmen eines **Teamprojekts** für die **Modulabschlussprüfung AM 1: Medieninformatik** entwickelt wurde. Ziel des Spiels ist es, verschiedene Rätsel und Hinweise zu lösen, um den Fall als Detektiv erfolgreich abzuschließen.  

Dieses Repository enthält **nur die Scripts** des Spiels. **Assets, große Dateien und fertige Builds** sind aus **lizenzrechtlichen Gründen** nicht enthalten. Das bedeutet:  

- Sie können das Spiel nicht direkt aus diesem Repository starten.  
- Die Scripts zeigen die komplette Logik und Struktur des Spiels.  
- Builds, Modelle, Texturen und Audio-Dateien wurden entfernt, um Lizenzprobleme zu vermeiden.  

---

## Installation & Nutzung

- Um das Spiel auszuführen, muss die fertige `.exe` verwendet werden (nicht im Repository enthalten).  
- Windows zeigt möglicherweise einen Warnhinweis an, da das Spiel **nicht signiert** ist. Diesen Hinweis einfach bestätigen, um das Spiel zu starten.  

---

## Projektstruktur
